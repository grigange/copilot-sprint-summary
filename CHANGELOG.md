# Changelog

## [0.1.0] - 2025-12-27

### Added
- 🚀 Initial public release
- Generate AI-powered sprint summaries from git commits
- Filter by date range and author
- Customizable output folder with folder picker
- Multiple date format options (ISO, European, US, etc.)
- Flexible file naming patterns with placeholders
- Custom open command for external apps (Obsidian, Notion, Typora)
- AI model selection from available Copilot models
- Customizable system prompt for team-specific formatting
- Status bar quick access button
- Professional settings UI with inline help

### Technical
- Uses VS Code Language Model API
- Supports up to 50 commits per summary
- Automatic file change detection per commit
